## Before uploading

1. Extract the ZIP.
2. Open the `england-mortality-deprivation-analytics` folder.
3. Confirm that `README.md`, `data`, `assets`, `scripts`, `docs` and `presentations` are inside it.
4. Run the two commands in the main README if you want to reproduce the checks locally.

## Upload through the GitHub website

1. Sign in to GitHub and create a repository with the suggested name.
2. Choose the visibility you want. For an empty repository, leave the automatic README, license and `.gitignore` options unselected because this package already includes the relevant project files and attribution notice.
3. On the empty repository page, choose the option to upload existing files.
4. Upload the **contents inside** the extracted project folder. This puts `README.md` at the repository root rather than inside another folder.
5. Include the dotfiles `.gitignore` and `.gitattributes` if your file picker hides them, or add them separately.
6. Use a commit message such as `Add mortality and deprivation analytics project`.
7. Open the repository homepage and check that the README, preview image and relative links render.

Uploading only the ZIP will store an archive but will not show the project README or browsable folders. The exact GitHub button labels can vary.

## Optional Git command-line route

In the extracted project directory:

```bash
git init
git add .
git commit -m "Add mortality and deprivation analytics project"
git branch -M main
```

Create an empty GitHub repository, then use its actual remote URL:

```bash
git remote add origin https://github.com/YOUR_USERNAME/england-mortality-deprivation-analytics.git
git push -u origin main
```

Replace `YOUR_USERNAME` before running the command. Sign in through your normal Git authentication method. Do not put passwords or tokens into repository files.
